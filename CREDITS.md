# Credits

## Artwork

All artwork comes from The Metropolitan Museum of Art's Open Access collection. The Met marks each
work public domain (`isPublicDomain: true`, checked through its collection API on 30 Oct 2026) and
releases the images under CC0. See https://www.metmuseum.org/about-the-met/policies-and-documents/open-access

| File in `assets/img/` | Work | Treatment |
|---|---|---|
| `hero-aristotle-1700.webp`, `hero-aristotle-900.webp` | Rembrandt van Rijn, *Aristotle with a Bust of Homer*, 1653, oil on canvas. https://www.metmuseum.org/art/collection/search/437394 | Resized, shadows deepened |
| `hero-aristotle-engraved.webp` | Same work | Redrawn as engraved line-work in gold |
| `plate-roman-port.webp`, `plate-roman-port-1000.webp` | Giovanni Battista Piranesi, *Parte di ampio magnifico Porto all'uso degli antichi Romani*, ca. 1749–50, etching. https://www.metmuseum.org/art/collection/search/338737 | Cropped, shown as a warm negative |
| `coin-caesar.webp` | Gold aureus of Julius Caesar, 46 BCE. https://www.metmuseum.org/art/collection/search/254853 | Cut out of its grey ground |
| `og-arjun-patel.jpg` | Detail of the Rembrandt | Social sharing image, with Arjun's name set in Cormorant |

Project figures in `assets/img/` come from Arjun's own project reports.
